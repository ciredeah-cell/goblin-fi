# goblin-fi

Homepage and privacy policy for Goblin-fi, a personal single-user tool that publishes and maintains videos on its owner's own YouTube channel.

These two pages exist because Google requires a homepage URL and a privacy policy URL for any application requesting access to a YouTube account, including single-user personal ones.

No application code lives here. This repository is only the two public pages Google links to from the OAuth consent screen.

- Home: https://ciredeah-cell.github.io/goblin-fi/
- Privacy policy: https://ciredeah-cell.github.io/goblin-fi/privacy.html
