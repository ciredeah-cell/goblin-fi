Goblin-fi

Privacy Policy

Last updated 17 September 2026

Goblin-fi is a personal, single-user tool. It manages one YouTube channel — the one belonging to its owner — and it collects no information from anyone else.

Who this applies to

There is exactly one user of this application: its owner, who is also the owner of the YouTube channel it publishes to. The application is not distributed, has no sign-up, and has no other users. If you are reading this and you are not that person, this policy describes software that holds no data about you.

What data the application accesses

When the owner authorises the application, Google issues it a credential for the scope https://www.googleapis.com/auth/youtube. The application uses that access solely to act on the owner's own channel:

  • upload videos
  • read back the list of videos on the channel
  • update video titles, descriptions, visibility and scheduling
  • delete videos it has superseded with a newer render

It does not read, request, or store data belonging to any other Google account, and it does not access viewer, subscriber, or comment data.

Where the credential is stored

The OAuth credential is written to a file on a single computer on the owner's private home network. It is not transmitted to any third party, not synced to any cloud service, and not stored on any server operated by anyone else. The application communicates only with Google's own APIs.

What is not done with your data

No data is sold, rented, shared, or transferred to third parties. There is no analytics, no advertising, no tracking, and no profiling. No human other than the owner has access to the credential or to anything the application reads.

Retention and deletion

The stored credential persists until it is revoked or deleted. The owner may revoke the application's access at any time from Google Account permissions, which immediately and permanently ends its ability to reach the channel. Deleting the credential file has the same practical effect locally.

Google API Services User Data Policy

Goblin-fi's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes to this policy

If what the application does changes, this page is updated and the date at the top changes with it.
